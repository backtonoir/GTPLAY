How to buy

Four steps to your item

The whole flow takes a few minutes. Keep your Order ID — you'll need it to track your order.

  1. Choose items

    Search or filter the store, then add items to your cart. Quantities are limited to the available stock.

  2. Checkout

    Enter your GrowID and confirm. You get an Order ID, an access code, and a 5-minute payment session.

  3. Pay with QRIS

    Scan the QRIS, pay the exact total, upload your payment screenshot, and tap I Have Paid.

  4. Copy your redeem code

    An admin checks your payment and adds your redeem code. Copy it from the payment page or Track Order and redeem it in game.

Payment guide — QRIS

  1. Open any banking or e-wallet app that supports QRIS.
  2. Choose Scan / Bayar QRIS and scan the code on the payment page.
  3. Enter the exact Total Payment shown on the page.
  4. Finish the payment and take a screenshot of the receipt.
  5. Upload the screenshot on the payment page and tap I Have Paid.

Good to know

  • The payment session lasts 5 minutes. Refreshing the page does not reset the timer.
  • Payments are verified manually by an admin — there is no automatic confirmation.
  • Your redeem code appears once the order is Completed — it stays on Track Order, so keep your Order ID and access code.
  • Paid after the timer ran out? Don't pay again — send your proof to the admin.

FAQ

Pertanyaan yang sering ditanyakan

Bagaimana cara membeli item?
Pilih item di Store, tekan Add to Cart, lalu buka keranjang dan tekan Checkout. Isi GrowID kamu, konfirmasi pesanan, kemudian selesaikan pembayaran QRIS di halaman pembayaran.
Bagaimana cara membayar melalui QRIS?
Scan kode QRIS dengan aplikasi bank atau e-wallet yang mendukung QRIS, masukkan nominal persis sesuai Total Payment, selesaikan pembayaran, lalu upload screenshot bukti bayar dan tekan I Have Paid. Lihat Payment Guide untuk langkah lengkapnya.
Berapa lama waktu pengiriman?
Item diberikan dalam bentuk redeem code oleh admin setelah pembayaran diverifikasi. Lamanya tergantung antrean pesanan dan jam aktif admin. Begitu pesanan berstatus Completed, redeem code muncul di halaman pembayaran dan di Track Order — tinggal tekan Copy lalu redeem di game.
Bagaimana jika pembayaran gagal?
Jika saldo belum terpotong, ulangi pembayaran selama sesi masih aktif. Jika saldo sudah terpotong tetapi status pesanan belum berubah, jangan membayar ulang — hubungi admin melalui WhatsApp dengan Order ID dan bukti pembayaran.
Bagaimana jika QRIS expired?
Sesi pembayaran berlaku 5 menit. Jika waktu habis sebelum kamu membayar, pesanan otomatis menjadi Expired dan stok dikembalikan — buat pesanan baru dengan tombol Order again. Jika kamu sudah terlanjur membayar setelah waktu habis, kirim bukti pembayaran ke admin agar bisa diperiksa secara manual.
Di mana saya mendapatkan redeem code?
Setelah admin menandai pesanan sebagai Completed, redeem code tampil di halaman pembayaran pesananmu dan di Track Order (masukkan Order ID + kode akses). Tekan Copy, lalu redeem di game GTPLAY. Jika code tidak bisa dipakai, hubungi admin dengan Order ID kamu.
Bagaimana cara mengecek status pesanan?
Buka halaman Track Order, lalu masukkan Order ID dan kode akses yang ditampilkan di halaman pembayaran. Pesanan yang dibuat dari perangkat ini juga tersimpan di sana untuk akses cepat.
Bagaimana cara menghubungi admin?
Hubungi admin GTPLAY melalui WhatsApp. Sertakan Order ID kamu agar admin bisa membantu lebih cepat.
