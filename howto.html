Mulai bermain

Cara Bermain di GTPLAY

GTPLAY adalah Growtopia Private Server (GTPS) tempat kamu bisa bermain Growtopia dengan fitur dan item eksklusif.

Apa itu GTPLAY?

GTPLAY adalah server privat Growtopia yang berjalan terpisah dari server resmi Ubisoft. Di GTPLAY, kamu bisa menikmati fitur-fitur khusus seperti item eksklusif, drop rate yang berbeda, dan event server yang dikelola langsung oleh tim admin GTPLAY.

Yang kamu butuhkan

  • Perangkat yang didukung: Windows, Android, iOS, atau Mac
  • Client GTPLAY (bukan client Growtopia resmi) — download di halaman Download
  • Koneksi internet yang stabil

Langkah memulai

  1. Download client GTPLAY dari halaman Download sesuai platform kamu.
  2. Install dan buka client yang sudah didownload.
  3. Buat akun baru — masukkan GrowID dan password yang kamu inginkan di layar login, lalu tekan tombol register/daftar.
  4. Masuk ke game — setelah akun dibuat, login dengan GrowID dan password yang sama.
  5. Mulai bermain! Kamu akan muncul di world START. Explore world lain, kumpulkan item, dan ikuti event server.
Penting: GTPLAY adalah server privat dan tidak berafiliasi dengan Growtopia atau Ubisoft. Akun GTPLAY terpisah dari akun Growtopia resmi.

Beli item

Cara Beli Item di Store

Proses pembelian hanya butuh beberapa menit. Simpan Order ID kamu untuk melacak pesanan.

  1. Pilih item

    Buka halaman Store, cari item yang kamu mau, lalu tekan Add to Cart. Kamu bisa menambahkan beberapa item sekaligus. Jumlah item dibatasi oleh stok yang tersedia.

  2. Checkout

    Buka keranjang belanja, tekan Checkout, lalu masukkan GrowID kamu dan konfirmasi pesanan. Kamu akan mendapat Order ID, kode akses, dan sesi pembayaran selama 5 menit.

  3. Bayar

    Pilih metode pembayaran (QRIS, GoPay, atau BCA), bayar dengan nominal persis sesuai Total Payment, upload screenshot bukti bayar, lalu tekan I Have Paid.

  4. Ambil redeem code

    Admin akan memeriksa pembayaran dan menambahkan redeem code di pesanan kamu. Salin code dari halaman pembayaran atau Track Order, lalu redeem di dalam game.

Panduan Pembayaran — QRIS

  1. Buka aplikasi bank atau e-wallet yang mendukung QRIS (GoPay, OVO, DANA, ShopeePay, m-banking, dll).
  2. Pilih menu Scan / Bayar QRIS dan scan kode QR di halaman pembayaran.
  3. Masukkan nominal persis sesuai Total Payment yang tertera.
  4. Selesaikan pembayaran dan ambil screenshot bukti bayar.
  5. Upload screenshot di halaman pembayaran dan tekan I Have Paid.

Panduan Pembayaran — GoPay

  1. Buka aplikasi Gojek atau GoPay kamu.
  2. Pilih Transfer ke nomor GoPay yang tertera di halaman pembayaran.
  3. Masukkan nominal persis sesuai Total Payment.
  4. Selesaikan transfer dan screenshot bukti pembayaran.
  5. Upload screenshot di halaman pembayaran dan tekan I Have Paid.

Panduan Pembayaran — Bank BCA

  1. Buka m-banking BCA, KlikBCA, atau ATM BCA.
  2. Transfer ke nomor rekening BCA yang tertera di halaman pembayaran.
  3. Masukkan nominal persis sesuai Total Payment.
  4. Selesaikan transfer dan screenshot/simpan bukti pembayaran.
  5. Upload screenshot di halaman pembayaran dan tekan I Have Paid.

Yang perlu diketahui

  • Sesi pembayaran berlaku 5 menit. Refresh halaman tidak mereset timer.
  • Pembayaran diverifikasi secara manual oleh admin — tidak ada konfirmasi otomatis.
  • Redeem code muncul setelah pesanan berstatus Completed dan tetap tersimpan di Track Order.
  • Sudah bayar tapi timer habis? Jangan bayar ulang — kirim bukti pembayaran ke admin via WhatsApp.
  • Nominal pembayaran harus persis. Jika kurang atau lebih, admin mungkin akan menolak pembayaran.

Login ke server

Cara Login per Platform

Panduan login untuk setiap platform yang didukung GTPLAY.

🖥️ Windows

  1. Download client GTPLAY untuk Windows dari halaman Download.
  2. Extract file ZIP ke folder yang kamu inginkan (misalnya C:\GTPLAY).
  3. Buka file Growtopia.exe dari folder hasil extract.
  4. Di layar login, masukkan GrowID dan Password kamu.
  5. Tekan Login untuk masuk ke server GTPLAY.
Tips: Jika muncul peringatan Windows Defender atau SmartScreen, pilih Run Anyway / More Info → Run Anyway. Client GTPLAY aman digunakan.

📱 Android

  1. Download file APK GTPLAY dari halaman Download.
  2. Jika belum mengizinkan instalasi dari sumber tidak dikenal, buka Settings → Security → Unknown Sources dan aktifkan.
  3. Buka file APK yang sudah didownload dan tekan Install.
  4. Setelah terinstall, buka aplikasi GTPLAY.
  5. Masukkan GrowID dan Password di layar login, lalu tekan Login.
Catatan: Pastikan kamu mendownload APK dari link resmi GTPLAY, bukan dari sumber lain, untuk keamanan akun.

🍎 iOS

  1. Download client GTPLAY untuk iOS dari halaman Download (jika tersedia).
  2. Ikuti instruksi instalasi yang diberikan — mungkin memerlukan sideloading menggunakan AltStore atau metode serupa.
  3. Setelah terinstall, buka aplikasi GTPLAY.
  4. Masukkan GrowID dan Password di layar login.
  5. Tekan Login untuk masuk.
Perhatian: Dukungan iOS mungkin terbatas dan memerlukan langkah tambahan. Hubungi admin jika mengalami kendala saat instalasi.

💻 Mac

  1. Download client GTPLAY untuk Mac dari halaman Download.
  2. Buka file yang sudah didownload dan pindahkan aplikasi ke folder Applications.
  3. Klik kanan aplikasi GTPLAY dan pilih Open (untuk bypass Gatekeeper saat pertama kali).
  4. Masukkan GrowID dan Password di layar login.
  5. Tekan Login untuk masuk ke server.
Belum punya akun? Masukkan GrowID dan password baru yang kamu inginkan di layar login, lalu tekan tombol Register. Akun langsung aktif dan bisa digunakan.

Starterpack

Cara Ambil Starterpack

Setiap pemain baru di GTPLAY berhak mendapat starterpack gratis untuk memulai petualangan.

  1. Login ke GTPLAY

    Buka client GTPLAY dan login menggunakan GrowID dan password kamu. Pastikan akun sudah terdaftar.

  2. Pergi ke world START

    Setelah masuk, ketik /go START di chat untuk pergi ke world START. Di sini kamu bisa menemukan informasi penting tentang server.

  3. Cari NPC atau papan Starterpack

    Di world START atau world yang ditunjukkan, cari NPC atau papan informasi bertuliskan Starterpack. Sentuh atau punch untuk mengambil starterpack kamu.

  4. Cek inventory

    Starterpack akan masuk ke inventory kamu secara otomatis. Buka inventory untuk melihat item yang kamu terima dan mulai gunakan!

Tips Starterpack

  • Starterpack hanya bisa diambil satu kali per akun.
  • Isi starterpack dapat berubah sewaktu-waktu sesuai update server.
  • Jika kamu tidak bisa mengambil starterpack, kemungkinan akun kamu sudah pernah mengambilnya atau ada kendala — hubungi admin.
  • Jangan buang item starterpack sembarangan — beberapa item berguna untuk awal permainan.

Strategi

Cara Profit di GTPLAY

Tips dan strategi untuk mengumpulkan World Lock dan item berharga di server GTPLAY.

Farming

Farming adalah cara paling dasar untuk mendapatkan Gems dan item. Tanam seed, panen, dan jual hasilnya. Beberapa tips farming:

  • Pilih seed yang profitable — cek harga jual tree vs harga beli seed. Seed dengan rarity tinggi biasanya lebih menguntungkan.
  • Gunakan Magplant untuk farming otomatis. Magplant bisa dibeli di Store dan sangat mempercepat proses farming.
  • Buat farm world yang luas dan efisien. Semakin banyak tree, semakin besar hasil panen.

Trading

Trading (jual-beli item antar pemain) adalah cara cepat untuk meningkatkan kekayaan:

  • Pelajari harga pasar — pantau harga item populer dan cari selisih harga (buy low, sell high).
  • Buat SELL world — buka world jual-beli dengan harga yang kompetitif untuk menarik pembeli.
  • Ikuti event server — item event biasanya langka dan harganya naik setelah event berakhir.

Event & Drop

Server GTPLAY sering mengadakan event dengan hadiah eksklusif:

  • Pantau halaman Announcement untuk info event terbaru.
  • Event Double Drop Rate adalah waktu terbaik untuk farming item langka.
  • Ikuti mini-game atau quest yang diadakan admin untuk hadiah spesial.

Tips Umum

  • Jangan scam — player yang ketahuan scamming akan di-ban dari server.
  • Amankan akun — gunakan password yang kuat dan jangan bagikan ke siapapun.
  • Jaga world kamu — pasang lock dan atur akses agar world tidak dirusak.
  • Gabung komunitas — ikuti Discord atau grup WhatsApp GTPLAY untuk tips dan info trading.
