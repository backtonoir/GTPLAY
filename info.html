About GTPLAY

GTPLAY adalah Growtopia Private Server. GTPLAY Store adalah toko resmi server untuk membeli item in-game GTPLAY menggunakan pembayaran QRIS.

Setiap pembayaran diperiksa oleh admin secara manual sebelum item diberikan dalam bentuk redeem code. GTPLAY tidak berafiliasi dengan Growtopia maupun Ubisoft.

Terms & Conditions

  1. Item yang dijual hanya berlaku di server GTPLAY dan tidak memiliki nilai di luar server.
  2. Pembeli wajib memasukkan GrowID yang benar sebagai identitas pesanan.
  3. Item diberikan dalam bentuk redeem code yang tampil di halaman pesanan setelah status Completed. Redeem code bersifat rahasia — jangan dibagikan ke orang lain.
  4. Pembayaran dilakukan melalui QRIS dengan nominal persis sesuai Total Payment, dalam batas waktu sesi pembayaran (5 menit).
  5. Pesanan diproses setelah admin memverifikasi pembayaran. Tidak ada verifikasi pembayaran otomatis.
  6. Pesanan yang tidak dibayar sampai sesi berakhir akan berstatus Expired dan stok dikembalikan.
  7. Admin berhak menolak pembayaran yang tidak sesuai (nominal berbeda, bukti tidak valid, atau terindikasi penipuan).
  8. Harga dan stok dapat berubah sewaktu-waktu. Harga yang berlaku adalah harga saat pesanan dikonfirmasi.

Refund Policy

Karena item bersifat digital dan dikirim manual, pengembalian dana ditangani kasus per kasus oleh admin:

  • Jika pembayaran sudah diverifikasi tetapi redeem code tidak bisa dipakai, hubungi admin untuk penggantian code atau pengembalian dana.
  • Redeem code yang sudah berhasil dipakai tidak dapat dikembalikan.
  • Redeem code yang dibagikan atau dipakai orang lain menjadi tanggung jawab pembeli.
  • Jika kamu membayar setelah sesi expired atau membayar dua kali, kirim bukti ke admin agar dapat diperiksa.
